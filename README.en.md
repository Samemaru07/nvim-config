## ⭐ Features

- 🎨 Colorscheme: [kanagawa.nvim](https://github.com/rebelot/kanagawa.nvim)
- 📦 Plugin Management: [lazy.nvim](https://github.com/folke/lazy.nvim) (Auto-installed on startup)
- 🔧 LSP: Automatic setup with [Mason](https://github.com/williamboman/mason.nvim).
- 🌸 Dashboard: Greeted with ASCII art and a message from Mion Sonozaki (**Higurashi When They Cry**)
- 💬 Notifications: Characters send messages whenever you copy, paste, cut, or delete (**Code Geass, Rascal Does Not Dream of Bunny Girl Senpai, Kantai Collection, Chainsaw Man, Ghost in the Shell: S.A.C.**)
- ⚔️ Status Line: "Saving is no big deal!", "I'll save a file like that!!" (**Mobile Suit Gundam & Z Gundam**)

## 📋 Prerequisites

- OS: Linux (WSL is also supported)
    - Verified to work on Arch Linux and Ubuntu (WSL).
    - Package management instructions in this repository use Arch's `pacman` and Ubuntu's `apt`.

## 📁 Directory Structure

```
nvim/
    ├ init.lua              # Entry point
    ├ lazy-lock.json        # Plugin version lockfile
    ├ lua/
    │   ├ core/             # Options, keymaps, autocmds
    │   ├ plugins/          # Plugin configurations (lazy.nvim)
    │   └ data/             # Notification message data
    ├ .clang-format         # Formatter for C-family languages (C, C++, Objective-*)
    └ assets/               # Images for README
```

## 🚀 Installation

##### 0. Preparation

```bash
# For Arch Linux
sudo pacman -S git curl
# For Ubuntu
sudo apt install git curl
```

##### 1. Clone the repository

```bash
git clone https://github.com/Samemaru07/nvim-config ~/.config/nvim
```

##### 2. Install dependencies

Required packages to run Neovim.

<details>
<summary>For Arch Linux</summary>

```bash
sudo pacman -S lazygit npm nodejs unzip wl-clipboard deno less zathura python-pip
pip install --user neovim-remote  # nvr
```

</details>

<details>
<summary>For Ubuntu</summary>

```bash
sudo apt install lazygit npm nodejs unzip deno less zathura python3-pip
pip install --user neovim-remote  # nvr
```

In a WSL environment, `win32yank.exe` is required to share the clipboard with Windows.

```bash
mkdir -p ~/.local/bin
curl -sLo /tmp/win32yank.zip https://github.com/equalsraf/win32yank/releases/latest/download/win32yank-x64.zip
unzip -p /tmp/win32yank.zip win32yank.exe > ~/.local/bin/win32yank.exe
chmod +x ~/.local/bin/win32yank.exe
rm /tmp/win32yank.zip
```

</details>

##### 3. Anaconda Environment Setup

Supports executing Jupyter Notebook (`.ipynb`) files.
This is not mandatory.

Since Anaconda environments (including packages) are not shared between Arch Linux and WSL, **they must be set up separately for each OS**.

```bash
conda create -n py313 python=3.13
conda activate py313
pip install pynvim jupyter_client
```

`python3_host_prog` in `core/options.lua` assumes the following path:

```lua
vim.g.python3_host_prog = vim.fn.expand("~/anaconda3/envs/py313/bin/python")
```

##### 4. Install SKK Dictionary

Required if you use Japanese input with skkeleton.
This is not mandatory.

```bash
mkdir -p ~/.skk
curl -o ~/.skk/SKK-JISYO.L https://raw.githubusercontent.com/skk-dev/dict/master/SKK-JISYO.L
```

> **💡 Note:** The user dictionary (`~/.skkeleton`) is automatically generated by skkeleton upon the first conversion, so manual creation is not required.

##### 5. TeX Environment Setup

Required if you want to compile and preview LaTeX (`.tex`) files.
This is not mandatory.

<details>
<summary>For Arch Linux</summary>

```bash
sudo pacman -S texlive-basic texlive-latex texlive-latexextra texlive-luatex texlive-langjapanese zathura zathura-pdf-mupdf
```

- If you have enough storage space, you can perform a full installation as follows (`texlive-meta` does not include the Japanese environment, so it must be specified separately):

```bash
sudo pacman -S texlive-meta texlive-langjapanese zathura zathura-pdf-mupdf
```

</details>

<details>
<summary>For Ubuntu</summary>

```bash
sudo apt install texlive-latex-extra texlive-luatex texlive-lang-japanese latexmk zathura
```

- If you have enough storage space, you can perform a full installation as follows:

```bash
sudo apt install texlive-full zathura
```

</details>

##### 6. First Startup

```bash
nvim
```

> **💡 Tip:** Upon startup, lazy.nvim will automatically install the plugins.
> Mason will also automatically set up the LSP servers.

## ⌨️ Keymaps

- `<leader>`, `<localleader>` map to the Space key.
- `<C>: Ctrl`, `<A>: Alt`, `<S>: Shift`.
- Mode abbreviations: `n` = Normal, `i` = Insert, `v` = Visual, `c` = Command, `t` = Terminal, `s` = Select, `o` = Operator-pending [^footnote]
    [^footnote]: `s` (Select) and `o` (Operator-pending) are mainly used internally by plugins. You generally don't need to be aware of them during normal operation.
- In this configuration, copy = yank, meaning whatever is sent to the register is sent to the system clipboard.

<details>
<summary>How to create Braille ASCII Art</summary>

Created using [this site](https://lazesoftware.com/ja/tool/brailleaagen/).

1. Prepare the image you want to convert to Braille AA.
    - The blush on the cheeks seems hard to recognize, so paint it in dark gray and add white highlights.
    - Detailed shadows stand out strangely in AA, so keep colors like hair consistent.
    - Since the background will also become AA and obscure Mion, paint the background completely white.
2. Access the link above, select `From Image` (画像から), set the `Scaling` (拡大縮小) to about 30%, open `Advanced Settings` (詳細設定), check `Invert Negative/Positive` (ネガポジ反転する), and click the `Execute` (実行) button.
    - It's easier to see if you adjust the font size to match your actual font size and use a black background. (You can also adjust the text block size of the `Result`).
3. Click the `Copy to Clipboard` button and assign it to `header_art` in `lua/plugins/alpha.lua`.
    - It's best to trim the top and bottom slightly so the quote remains visible.

<summary>How to Change Status Messages</summary>

- If you want to edit status messages, please modify the `lualine_c` table section in `lua/plugins/lualine.lua`.

```lua
        lualine_c = {
            {
                function()
                    if vim.bo.buftype == "terminal" then
                        return ""
                    end
                    local ft = vim.bo.filetype
                    if ft == "neo-tree" then
                        return ""
                    end
                    if ft == "alpha" then
                        return ""
                    end

                    if vim.bo.modified then
                        return "<Message when unsaved>"
                    else
                        return "<Message when saved>"
                    end
                end,
                color = nil,
            },
        },
```

### Integration with Hyper

While editing a `.md` file, running the `:MarkdownPreview` command will send the local server URL to your clipboard via `markdown-preview.nvim`.

> You'll get a report (notification) from Tachikoma. Ahem!

By using the [Hyper with built-in Webview](https://github.com/Samemaru07/hyper-webview-fork/tree/main) that I implemented, you can split the pane, `echo` that URL, and click it to easily implement real-time synchronization without having to manually line up a browser next to it!
